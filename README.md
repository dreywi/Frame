# Recipe Service

## Назначение
Веб-сервис для публикации и поиска кулинарных рецептов. Позволяет автору
опубликовать рецепт с ингредиентами и шагами приготовления, а читателю
найти подходящий рецепт и пересчитать ингредиенты на нужное число порций.

## Целевая аудитория
Домашние кулинары, которые ищут рецепты и ведут личную коллекцию, и
авторы, публикующие собственные рецепты.

## Предметная область
Рецепт описывается названием, автором, временем приготовления, числом
порций, калорийностью и списком ингредиентов с количествами. Рецепты
относятся к категориям (завтраки, супы, выпечка) и получают оценки
и комментарии пользователей.

## Основные сущности
- Пользователь
- Рецепт
- Ингредиент
- Категория
- Оценка (отзыв)

## Основные функции
- просмотр карточки рецепта;
- пересчет количества ингредиентов на заданное число порций;
- расчет калорийности выбранного объема порций;
- подбор рецепта по ограничению времени приготовления;
- проверка статуса публикации рецепта.

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
